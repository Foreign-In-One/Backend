# PayCycle AI 색상 명세

이 문서는 `src/styles.css`와 공통 버튼 컴포넌트를 기준으로 정리한 앱 전체 색상표입니다.  
모든 값은 **HEX**이며, `/90`, `/80` 같은 투명도 색상은 `#RRGGBBAA` 형식도 함께 표기합니다.

## 9. 색상 운용 규칙

- 주요 CTA와 활성 내비게이션은 `#143463`을 사용합니다.
- 성공, 경고, 안내, 오류는 각각 Green `#009962`, Orange `#F19024`, Blue `#4F8AC6`, Red `#E7000B`로 구분합니다.
- 아이콘은 별도 임의 색상보다 같은 컴포넌트의 텍스트 색상을 상속합니다.
- 비활성 상태는 해당 요소 전체에 50% 투명도를 적용합니다.
- 포커스 상태는 배경색을 바꾸지 않고 `#5072A6` 링으로 표시합니다.
- 투명도가 있는 색은 실제 화면에서 뒤쪽 배경과 합성되므로 눈에 보이는 최종값이 배경에 따라 달라질 수 있습니다.
